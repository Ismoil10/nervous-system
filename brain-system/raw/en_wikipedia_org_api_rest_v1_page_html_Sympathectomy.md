A **sympathectomy** is an irreversible procedure during which at least one [sympathetic ganglion](./Sympathetic_ganglion "Sympathetic ganglion") is removed. One example is the lumbar sympathectomy, which is advised for occlusive arterial disease in which L2 and L3 ganglia along with intervening sympathetic trunk are removed leaving behind the L1 ganglion which is responsible for ejaculation. Another example is [endoscopic thoracic sympathectomy](./Endoscopic_thoracic_sympathectomy "Endoscopic thoracic sympathectomy").

## Indications

- [Hyperhidrosis](./Hyperhidrosis "Hyperhidrosis")[[1]](./Sympathectomy#cite_note-:0-1)
- [Raynaud syndrome](./Raynaud's_phenomenon "Raynaud's phenomenon")[[1]](./Sympathectomy#cite_note-:0-1)

- [Neuropathic](./Peripheral_neuropathy "Peripheral neuropathy") pain, although this is controversial[[2]](./Sympathectomy#cite_note-2)
