Source: https://en.wikipedia.org/api/rest_v1/page/html/Vasopressin

Vasopressin

Mammalian hormone released from the pituitary gland



This article is about the natural peptide in mammals. For the medication, see [Vasopressin (medication)](./Vasopressin_(medication) "Vasopressin (medication)").

Not to be confused with [vasopressors](./Antihypotensive_agent "Antihypotensive agent") generally, of which it is but one example.
